# Shopping — App móvil

Expo SDK 58 · React Native 0.88 · TypeScript. La documentación completa
(puesta en marcha, flujos, variables y checklist de producción) vive en el
[README raíz](../README.md).

```bash
npm install
npx expo start        # escanea el QR con Expo Go
npm run typecheck     # verificación de tipos
```

Antes de correr: en `src/config.ts` deja `API_URL` con la IP LAN de la
máquina que ejecuta el backend (`backend/`).
